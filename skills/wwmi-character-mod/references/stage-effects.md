# 阶段换装、溶解与燃烧效果

用于“常态正常、高层缺衣料”“爆衣阶段不一致”及阶段性原皮残留。常态制作完成、逐层检查、精确复刻效果是不同交付范围。

## 对照证据

建立状态表，分别记录裙身、披纱、袖饰、头发、身体效果：保留/消失、燃烧区域、证据及未确定项。离火计数和大招后的短时状态分别记；只拍整数层数不能证明过渡时序一致。

- 官方PV常是演出，没有层数标签时不能用时间轴映射层数。
- 第三方标层实机图可比较部件存在与否，但注明发布来源，不能称为官方逐阶段验证或同客户端控制实验。
- 每次截图确认出场角色、计数/用户确认、全身和下摆是否入画；队伍头像不等于当前出场角色。不同光照不宜比较精确颜色/发光强度。
- 没有独立阶段选择器不等于没有阶段效果；保留的顶点数据和原游戏参数仍可能驱动变化。手动热键模拟层数也不证明跟随真实游戏状态。

## 定位顺序

1. 比较最后正常层与首次异常层。先确定衣料是否一直缺失，还是随阶段变化消失。
2. 用实际日志核对原draw与替换draw。衣料仍提交但不可见，再检查shader的溶解、alpha、剔除和深度；不直接改成强制常驻。
3. 在材质覆盖前采集必要CB，结合当前VS/PS追踪最终discard的来源。CB槽位、大小和寄存器在不同pass不通用。操作方法见 [runtime-debugging.md](runtime-debugging.md)。
4. 追踪实际数值：阶段阈值是否使整个遮罩范围落在不可见区？仅看到一个phase=1不能推断它对应哪个层数、含义或其他客户端的行为。
5. 同时检查普通/燃烧PS的基色与效果采样接口。同一VS不保证同一贴图槽位。只修外侧或常态不能覆盖高层底面。

## 定向修正规则

目标来自参考中的部件行为。例如高层仍保留裙身/披纱、袖饰消失，应分别处理它们；共用默认衣料通道可能把本应不同的效果绑在一起。

- 在确认的溶解因子处修正，用本Mod逐draw门控，保留其他裁切、镜头淡出及非目标角色原路径。不全局删除discard。
- 对本应保留的大块衣料绕过“完全溶解”只能修复保留范围，不能冒充官方边缘燃烧、亮度和时序。记录为局部适配规则。
- 局部异常发光可试验拆出原有三角形并限制已确认的发光输出；先核验该render target语义。不可把任意o0都当发光，强制归零可能抹掉正常着色。保留上身/手臂所需效果并检查下半身明暗；拆分检查见 [geometry-and-build.md](geometry-and-build.md)。
- 额外纹理槽与参数均需查冲突、保存/恢复，嵌套命令避免覆盖保存值。普通/燃烧的基色重定向不得覆盖效果纹理；插件组合后的控制流见运行时参考。

## 验证及停止范围

对受影响阶段、恢复常态及具体回归角度做相应验证。区分静态正则匹配、实际编译指令、截图和用户确认；文件头或新规则名不是画面通过证据。

每次构建记录安装哈希及截图对应版本。增量版本验证结果不能扩大成“最后版本所有状态均实测”。必要检查通过后停止重复采集；精确边缘或时序仍未解决时明确交付边界，不宣称全部一致。

本次长离的数值、已应用规则和剩余差异见 [changli-case.md](changli-case.md)，不要直接套用它的寄存器、阶段阈值、局部坐标或参数槽。
