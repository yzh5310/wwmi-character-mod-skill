# 网格、权重与构建

已有可用三维部件、仅需接口适配时，可以直接读取二进制并使用上游模板构建，无需强制安装 Blender。需要原创建模、重新拓扑、UV 或手工权重时再选 Blender 等合适工具；参考图不会自动补齐这些数据。

## 二进制接口

从 fmt 读取 stride、SemanticName/Index、Format、AlignedByteOffset、索引格式。字段宽度结合格式与下一偏移核对。保留 packed 字段时复制原始字节，避免无意重编码 SNORM、半精度 UV 或颜色。

长离采用 WWMI merged 模板的 Position、Vector、Color、TexCoord、Blend、Index 和 ShapeKey 缓冲区；其他版本应读当前模板。COLOR1 可能是辅助数据；贴图 alpha 可能是材质参数，不是透明度。离线预览误用 alpha 会产生虚假的淡色/透视。

## 骨骼转移

1. 先确定语义和供体部件，再用最近点、表面投影或骨骼对应。距离小不等于骨骼正确。
2. 用 Metadata 的 vg_map 转换局部到合并编号；核对键与源索引，不默认任意字典顺序都可靠。
3. 四影响接口不能直接装八影响。合并重复骨骼、保留合适影响、重新归一化；例如 UNORM8 权重总和255。
4. 合并编号超过255时用模板支持的逐部件重映射，不能简单取模丢掉高位。
5. 检查左右侧、髋部、缝合边、裙摆、袖口、装饰的权重跳变，特别是皮肤误继承衣料物理骨骼。

分别统计“供体参考点变化”与“最终权重变化”。长离分别为1,603和40，不把前者全部称作错误权重修复数。

## 表情与形变

同名或相同键数不证明编号相同。验证拓扑、顶点顺序和位置后才按索引复制脸部 deltas。身体 ShapeKey 的编号和范围另行核对；最近邻迁移、源键重编号与直接复用是不同方案。未应用的实验映射不要写成已实施。

## 检查清单

- 缓冲区字节数等于顶点数乘stride；索引有效、三角形索引数可被3整除。
- 非零权重指向有效骨骼，权重和正确；位置与形变有限；ShapeKey偏移单调且总数匹配。
- draw count/start 在 Index 范围内；合并不漏画、不重复画原组件。
- 为局部材质或发光拆draw时，保留三角形顶点编号及绕序，核验重排前后三角形多重集相同、draw区间覆盖且不重叠，骨骼/形变接口仍有效；不能只比总索引数。
- INI section不重名，资源/命令/依赖在实际安装位置能解析。
- 安装与输出哈希一致。回退文件置于不会被递归加载的位置，或按实际exclude规则禁用。

内存压力下可为构建进程设 `OPENBLAS_NUM_THREADS=1`，不要随意结束用户其他程序。
